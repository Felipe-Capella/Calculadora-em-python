# Calculadora em Python

Minha primeira calculadora desenvolvida em Python durante os estudos na EBAC.

## Funcionalidades
- Soma, subtração, multiplicação e divisão
- Menu interativo em loop (`while`)
- Tratamento de erro para entradas não numéricas (`try/except`)
- Validação para evitar divisão por zero

## Como executar
Abra o arquivo `Calculadora.ipynb` no Google Colab ou Jupyter Notebook e execute a célula.
